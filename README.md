🛒 ShopSale POS: Smart Retail Management & Billing System
​ShopSale POS is a cloud-connected, full-stack retail store management and billing application designed to bridge the gap between traditional local retail shops (which rely on physical notebooks) and modern digital software analytics.

​🌟 Key Features & Purpose
​Digital Notebook Conversion: Shop owners can take their end-of-day sales records or local language text notes and seamlessly convert them into structured digital software analytics.
​Smart Stock & Expense Tracking: Automatically tracks day-by-day sales, monitors which stocks are running low or sold out, and calculates total expenditures instantly.
​Backend-Driven AI Document/Bill Scanner: Features an integrated AI receipt scanner where heavy processing and parsing run securely on the backend (C# ASP.NET Core API), keeping API keys and sensitive logic safe away from the client-side.
​Mid-to-High Level Security Architecture: Implements robust JWT authentication, role-based access control, and query-level multi-store data isolation (StoreID and UserId scoping) to completely prevent cross-tenant data leaks.
​🛠️ Tech Stack
​Backend: C# ASP.NET Core Web API, Entity Framework Core, LINQ
​Frontend: React.js (Vite), Tailwind CSS, Lucide Icons, Framer Motion
​Database & Cloud: Supabase PostgreSQL, hosted on Render
​AI Integration: Gemini AI models for document parsing and receipt data extraction
